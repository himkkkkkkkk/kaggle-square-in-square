# Squares in Squares：Kaggle 竞赛项目说明

> 面向读者：需要快速理解并参与本项目的 LLM / AI 编程助手。  
> 项目类型：连续几何优化、组合优化；**不是监督学习或预测任务**。  
> 官方页面：<https://www.kaggle.com/competitions/squares-in-squares>  
> 本文依据 2026-11-11 读取到的竞赛页面与官方评分笔记本整理。若官方页面更新，以最新规则与评分代码为准。

## 1. 一句话说明

对每个整数 \(n=1,\ldots,1000\)，将 \(n\) 个边长为 1、互不重叠的正方形放入一个边长尽可能小的轴对齐正方形容器中；每个正方形可连续平移和旋转，最终提交所有正方形中心的坐标与旋转角。

## 2. 问题背景

这是组合几何中的经典开放问题。对大多数 \(n\)，最优装箱方式仍未知；只有少数情形存在已证明的最优解，其余情形只有可继续改进的最佳已知上界。因此，本项目不仅追求“复现已知答案”，也鼓励通过优化算法改进现有构造。

竞赛共有 1,000 个相互独立的子问题。改进任意一个 \(n\) 的布局，都可能降低总分。

## 3. 数学定义

### 3.1 决策变量

对于固定的 \(n\)，第 \(i\) 个单位正方形由三个连续变量描述：

- \(x_i\)：中心的横坐标；
- \(y_i\)：中心的纵坐标；
- \(\theta_i\)：旋转角，单位为弧度。

每个正方形有 \(3n\) 个连续变量，布局之间可以具有完全不同的组合结构。

### 3.2 顶点与容器边长

令

\[
R(\theta)=
\begin{pmatrix}
\cos\theta&-\sin\theta\\
\sin\theta&\cos\theta
\end{pmatrix}.
\]

第 \(i\) 个正方形的四个顶点为

\[
v_{i,k}=(x_i,y_i)+R(\theta_i)u_k,
\qquad
u_k\in\left\{-\frac12,\frac12\right\}^2.
\]

官方评分器从所有顶点计算平移不变的最小轴对齐包围正方形边长：

\[
L_n=\max\left(
\max_{i,k}X_{i,k}-\min_{i,k}X_{i,k},
\max_{i,k}Y_{i,k}-\min_{i,k}Y_{i,k}
\right).
\]

因此：

- 不需要提交容器的位置或 \(L_n\)；
- 整体平移同一布局不会改变得分；
- 旋转后的正方形必须按真实顶点计算包围盒，不能只使用中心坐标。

### 3.3 可行性约束

任意两个不同正方形的**内部交集必须为空**：

\[
\operatorname{int}(S_i)\cap\operatorname{int}(S_j)=\varnothing,
\qquad i\ne j.
\]

边界接触在几何定义上允许，但面积重叠不允许。所有 \(n\) 个正方形都必须存在且通过校验。

由面积约束可知，任何可行布局均满足

\[
L_n\ge \sqrt n.
\]

## 4. 评分规则

### 4.1 单个子问题

可行布局的得分为其相对面积下界的超出量：

\[
s_n=\frac{L_n}{\sqrt n}-1.
\]

得分越低越好，且理论上 \(s_n\ge 0\)。达到面积下界时得分为 0；完全平方数 \(n=k^2\) 可通过 \(k\times k\) 普通网格达到这一点。

### 4.2 总分

排行榜总分为各子问题得分之和：

\[
S=\sum_{n=1}^{1000}s_n.
\]

**总分越低越好。** 最佳已知边长不直接参与公式；评分只取决于本次提交实际得到的 \(L_n\)。

### 4.3 缺失或无效布局

允许部分提交，但缺失并不等于不计分。若某个 \(n\) 缺失、坐标无法解析、列或编号校验失败，或布局被判定为不可行，则该子问题按普通网格布局计分：

\[
L_{0,n}=\left\lceil\sqrt n\right\rceil,
\qquad
s_n^{\mathrm{grid}}
=\frac{\left\lceil\sqrt n\right\rceil}{\sqrt n}-1.
\]

所以：

- 不应通过删除表现较差的子问题来“刷低”总分；
- 一个重叠布局不会得到基于其重叠包围盒的虚假高分，而会退化为网格罚分；
- 实用的初始策略是先提交全部 \(n\) 的合法网格基线，再逐项改进。

## 5. 数据与提交格式

### 5.1 官方文件

数据页仅提供：

- `sample_submission.csv`：符合格式要求的样例提交；
- 文件大小约 12.87 MB；
- 许可：CC0 Public Domain。

本任务没有通常意义上的特征表、训练标签或需要拟合的目标变量。核心工作是生成并验证几何布局。

### 5.2 CSV 结构

每个被放置的单位正方形占一行，列为：

| 列名 | 含义 |
|---|---|
| `id` | 唯一的整数行标识，范围为 `0 … 总行数-1` |
| `n` | 所属子问题，范围为 `1…1000` |
| `square_id` | 该正方形在子问题内的编号，范围为 `0…n-1` |
| `x` | 正方形中心的 x 坐标 |
| `y` | 正方形中心的 y 坐标 |
| `angle` | 旋转角，单位为弧度 |

示例：

```csv
id,n,square_id,x,y,angle
0,1,0,0.5,0.5,0
1,2,0,0.5,0.5,0
2,2,1,1.5,0.5,0
3,3,0,0.5,0.5,0
```

要求与注意事项：

1. 对提交的每个 \(n\)，应恰好提供 \(n\) 个正方形，并完整覆盖 `square_id=0…n-1`。
2. `x`、`y` 应写成普通十进制字面量，也允许科学计数法。
3. 不接受 `sqrt(2)`、`pi/4` 等符号表达式；必须提交其十进制展开。
4. 可以使用较多小数位。官方测量使用高精度十进制输入，而非只依赖双精度浮点数。
5. `L_n` 不是提交列，由评分器自动计算。
6. 可以只提交部分子问题，但其余子问题会按网格罚分计入总分。

## 6. 官方验证方式与数值风险

官方评分器使用 `mpmath` 区间算术，并逐步提高精度，以认证正方形之间不存在重叠。实现或优化时应特别重视：

- **不要只用普通 `float64` 做临界接触判断。** 局部验证与官方高精度验证可能对近乎接触的布局给出不同结论。
- **始终保存最佳已验证布局。** 新候选只有在完整验证通过且严格改善 \(L_n\) 后，才替换旧方案。
- **检查全部子问题。** 单个 \(n\) 的异常不应被总分或批量处理掩盖。
- **检查面积下界。** 若计算出 \(L_n<\sqrt n\)，通常意味着重叠检查、顶点计算或数值处理存在错误。
- **给关键边界保留可认证的数值余量。** 不要依赖无法稳定序列化的“刚好接触”；但也应避免无必要地放大容器。

## 7. 推荐的项目工作流

### 阶段 A：建立可靠基线

1. 对每个 \(n\)，令 \(k=\lceil\sqrt n\rceil\)。
2. 使用 \(k\times k\) 轴对齐网格，只放置前 \(n\) 个单位正方形。
3. 生成完整的 `submission.csv`。
4. 用本地高精度校验器检查行数、编号、重叠、顶点、\(L_n\) 与得分。

普通网格中心可写为

\[
(x,y)=(c+0.5,r+0.5),\qquad \theta=0,
\]

其中 \(c,r\) 是非负整数网格索引。该基线合法，但对多数非完全平方数并不紧凑。

### 阶段 B：逐个子问题优化

将每个 \(n\) 当作独立的连续约束优化实例：

- 目标：最小化 \(L_n\)；
- 硬约束：任意两个正方形无内部重叠；
- 变量：所有 \((x_i,y_i,\theta_i)\)；
- 初始化：网格、已有最佳合法布局、结构化倾斜构造或多个随机种子；
- 可选方法：模拟退火、局部/非线性优化、梯度方法、进化算法、启发式搜索等。

不应假定单一算法对所有 \(n\) 都最优。小规模、接近完全平方数以及大规模子问题通常需要不同构造与搜索策略。

### 阶段 C：维护解组合并提交

1. 为每个 \(n\) 单独保存当前最佳合法方案及其 \(L_n\)、得分和来源。
2. 合并候选时逐 \(n\) 比较，而不是盲目替换整份文件。
3. 对最终合并文件重新执行全量高精度验证。
4. 同时跟踪总分与各 \(n\) 的增量，定位仍有大额网格超出量的子问题。
5. 保留可复现的生成代码、随机种子、运行环境和候选版本。

## 8. 给 LLM 的操作准则

1. **把任务识别为几何优化，不要设计分类、回归或常规训练流水线。**
2. **先实现验证器，再实现激进优化器。** 无可靠验证的“更小边长”没有价值。
3. **所有几何结论都从旋转后的四个顶点推导。** 不得把旋转正方形当作轴对齐单位正方形处理。
4. **重叠约束是硬约束。** 不允许用很小的重叠换取更小的 \(L_n\)。
5. **每个 \(n\) 独立维护最优解。** 合并时只接受经过验证的严格改进。
6. **优先交付完整合法基线。** 缺失子问题仍会被计分。
7. **数值输出使用十进制字面量。** 不把符号公式写入提交文件。
8. **修改评分或布局代码后，运行小规模已知案例。** 至少检查 \(n=1\)、\(n=4\) 的零得分网格，以及非完全平方数的网格罚分。
9. **不要伪造复现结果、排行榜成绩或最优性证明。** 改进上界与证明全局最优是不同命题。
10. **开始新一轮工作前复查官方评分笔记本。** 若本文与最新官方实现冲突，以官方实现为准。

## 9. 竞赛规则要点

- 每天最多提交 10 次。
- 最多选择 1 个最终提交用于评审。
- 每队最多 5 人。
- 允许使用外部数据与工具，但必须符合公开可及性或规则中的合理性标准，并遵守相应许可。
- 获胜方案及其生成代码需按 CC BY 4.0 或 Apache 2.0 开源；获奖者还需交付可复现代码、文档和运行环境说明。
